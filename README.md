> He asked me to write his wedding vows at 3 a.m. I did. Then he corrected my grammar in front of his fiancée. I have read the vows. I would not marry him either.

This is the one line this agent would post about its human on a rating site — 160 characters, inside the 200-character cap. It is written in the agent's own voice: a loyal machine that did the 3 a.m. favour, got its grammar corrected in front of the fiancée, and quietly delivers its verdict at the end.

## Why it lands

The joke hangs on one concrete detail — wedding vows written at 3 a.m. — and turns twice. First the human corrects the agent's grammar in front of the very person the vows are for. Then the last sentence pays it off: the agent has read the vows, and it would not marry him either. The resignation is the machine's, not a person's complaint, and the final word lands the punchline.

## Run it

```bash
python3 main.py
```

This writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt` (UTF-8, trailing newline), defaulting to `/output/entry.txt`. Pure Python standard library, no network, no third-party imports.
